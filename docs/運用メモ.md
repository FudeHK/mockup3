# ShopNavi 運用メモ（店主さま向け）

**使い始める前に：初期PINを必ず変えてください。**

## 1. 初期PINの変更方法
1. ShopNavi を開き、店舗コードと **管理者PIN** で入室します
2. 左（スマホは下）のメニューから **「設定」** を押します
3. 「管理者PIN」「スタッフPIN」それぞれに新しい番号（**6〜8桁の数字**）を2回入れて「変更」を押します
   - 管理者PINとスタッフPINは別の番号にしてください
   - PINは暗号化して保存されるため、あとから画面で確認できません。紙などに控えて安全な場所へ
4. スタッフには **スタッフPIN だけ** を伝えます（管理者PINは店主さまのみ）

> 5回続けてまちがえると、その端末は15分間入力できなくなります。時間をおいてから入れてください。

## 2. スタッフの呼び名（仮名）の追加方法
1. 管理者で入室 →「設定」→「スタッフの呼び名（仮名）」
2. 「スタッフD」のような **本名ではない呼び名** を入れて「追加」
3. 辞めた人の呼び名は「休止」にします（記録は残ります）

スタッフは入室後に自分の呼び名を選びます。名前や電話番号は保存しません。

## 3. CSV（利用記録）の出し方
1. 管理者で入室 →「ログ・CSV」
2. 開始日と終了日を選び、**「CSVを出力」** を押します
3. ダウンロードされたファイルは Excel でそのまま開けます（文字化けしません）

CSV には、マニュアルの作成時間・閲覧の記録・「わからない」・クイズの結果が入ります。

## 4. 毎日の使い方（ひとこと）
- **マニュアルを作る**：「マニュアル」→「新しく作る」→ テンプレートを選び、質問に答えて「公開する」
- **内容を直す**：編集して「更新して公開」→ スタッフに自動で「再確認のお願い」が出ます
- **「わからない」が届いたら**：「わからない」の画面で内容を確認し、説明したら「対応済み」を押します
- **ホーム画面に追加**：タブレットのブラウザの「共有」または「︙」メニューから「ホーム画面に追加」
